# 🛒 Smart Cart AI – Smart Retail Management & Billing System

**Smart Cart AI** is a smart retail management and billing application developed to simplify supermarket and grocery store operations. It provides a digital solution for managing products, processing customer bills, tracking inventory, and monitoring sales.

The project combines Python Flask with SQLite and a web-based interface to make retail operations easier and more organized.

## ✨ Features

- **Digital Billing:** Create and manage customer bills.
- **Product Management:** Manage product information and pricing.
- **Inventory Management:** Track product stock and availability.
- **Sales Monitoring:** Monitor sales information and transactions.
- **Customer Management:** Organize customer-related information.
- **Database Management:** Store application data using SQLite.
- **Web Interface:** Access the application through a browser.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/estherswetha/Smart-Cart-AI.git
```

### 2. Navigate to the Project Folder

```bash
cd Smart-Cart-AI
```

### 3. Create a Virtual Environment

```bash
py -3.13 -m venv venv
```

### 4. Activate the Virtual Environment

For Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install Flask

```bash
python -m pip install Flask
```

If the repository includes a `requirements.txt` file, install its dependencies using:

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

### 7. Open in Your Browser

```text
http://127.0.0.1:5000/
```
